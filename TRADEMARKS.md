# Name and logo

"Vox Trust" is the name of this project. The Apache-2.0 license covers the code; as its Section 6 says, it does **not** grant permission to use the project's name or marks except to describe where the work comes from.

In practice:

- You may say your software *implements*, *is based on* or *is compatible with* the Vox Trust protocol, as long as that is true.
- Please do not use the name or a similar one in a way that suggests your product is the official project or is endorsed by it.
- A formal conformance mark (a badge for implementations that pass the conformance suite) will be defined once a conformance suite exists.

If you are unsure, open an issue and ask.
