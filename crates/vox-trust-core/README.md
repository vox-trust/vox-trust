# vox-trust-core

Core types for the [Vox Trust protocol](https://github.com/vox-trust/vox-trust): the 102-bit seal layout and the trust-policy decision table.

**Pre-alpha. API unstable. No cryptography and no audio processing yet.** Do not use it to protect anyone. See the [draft spec](https://github.com/vox-trust/vox-trust/blob/main/spec/SPEC.md) and the [threat model](https://github.com/vox-trust/vox-trust/blob/main/spec/THREAT-MODEL.md).
