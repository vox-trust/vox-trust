# Governance

## Today

Vox Trust is a young, single-maintainer project.

- **Maintainer:** Roger Oliveira ([@rogeroliveira84](https://github.com/rogeroliveira84) · [LinkedIn](https://www.linkedin.com/in/rogeroliveira/)).
- **Decisions:** the maintainer decides, in the open. Changes to the specification happen through pull requests that explain the reasoning, and substantial ones are opened as issues first.
- **Stability:** the specification is at **version 0.2**. Its file-mode format is a **release candidate** (frozen unless a review finds a flaw; any incompatible change gets a new version number); the in-band parts are experimental. Version 1.0 comes after an outside review and a second, independent implementation.

## Where this is meant to go

A protocol that wants to be a reference should not depend on one person. The intended path:

1. Publish the specification, the threat model and the reference implementation in the open (this stage).
2. Get test vectors, external review, and at least **two independent implementations** that interoperate.
3. Move the specification to a neutral home (an open standards venue) once there is real interest from other parties.

This is an intention, not a commitment to any particular body or timeline.
